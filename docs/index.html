What to listen for.

The contour represents harmonic unexpectedness over time. It guides chord selection without changing the input melody.

  1. Start with the source. Learn the original harmonic rhythm and phrase boundary.
  2. Compare the same contour. Listen for where either model delays or releases tension.
  3. Switch the shape. Notice how the harmonic path changes while the melody stays fixed.
